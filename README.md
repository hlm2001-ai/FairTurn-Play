# FairTurn Play v3.0 — استديو الصف التفاعلي 🎓✨

**نسخة كاملة مجانية تعمل من ملف HTML واحد، دون حساب أو API مدفوع أو مكتبات خارجية.** عربي / English، متجاوبة مع شاشة الكمبيوتر والآيباد والهاتف. جميع بيانات الفصل وأسماء الطلاب ونتائجهم تُخزّن محليًا في متصفح المعلم/المعلمة.

## ما الجديد؟ — الميزات A إلى L

| الرمز | الميزة | كيف تعمل؟ |
|---|---|---|
| A | 🎡 عجلة الأسماء | عجلة دوّارة تختار من الطلاب الحاضرين الأقل حصولًا على فرص، مع نتيجة واضحة وعرض Spotlight |
| B | ⚡ طاقة الصف | يرتفع مقياس الطاقة بالمشاركة والتصفيق والاختبارات ونقاط الفرق؛ يفتح صندوق المكافآت عند 100% |
| C | 🎴 تحدي مفاجئ | بطاقات مفاجآت تحفز الجولة التالية: وقت أقصر أو نقاط مضاعفة أو مساعدة أو تصفيق وغيرها |
| D | 👏 تصفيق الصف | زر تصفيق مع صوت احتفال ومؤثرات، مرة واحدة لكل بطاقة تشجيع |
| E | 🃏 بطاقات التحدي | 10 ثوانٍ، نقاط ×2، اسأل صديقًا، بدون تلميحات، فرصة لفريق آخر، تصفيق جماعي |
| F | 🔥 Streak & badges | يراقب سلسلة الإجابات الصحيحة لكل طالب ويمنح 🌟 بعد 2 و🔥 بعد 3 و👑 بعد 5 |
| G | 🏅 لوحة الشرف | تعرض نجوم المشاركة، التطور اعتمادًا على سجل الإجابات، الفريق المتصدر، وأوسمة التميز |
| H | ⏱️ مؤقت دائري | يظهر المؤقت كحلقة حيّة مع لون تحذيري عند اقتراب النهاية، وخيارات 0/10/15/30/60/90 ثانية |
| I | 🔊 صوتيات تشجيعية | إيقاع اختيار وتصفيق واحتفال وأصوات تشجيع عبر Web Audio، مع تعليق منطوق اختياري عبر Speech Synthesis إن دعمه المتصفح |
| J | 🌟 Student Spotlight | عرض متحرك يظهر اسم الطالب المختار قبل بدء السؤال |
| K | 🎁 Bonus Chest | صندوق مكافآت بفتح متحرك يحصل منه الصف على نقاط للفريق أو امتيازات للسؤال التالي |
| L | 🤝 ساعد زميلك | اختيار زميل حاضر للمساعدة في المحاولة بعد الخطأ أو من بطاقة تحدي، دون إحراج الطالب |

بالإضافة إلى ذلك:
- إدخال اسم المعلم/المعلمة عند أول تشغيل مع اختيار 👩‍🏫 / 👨‍🏫، ويظهر في الترويسة. **لا يوجد تسجيل حساب أو كلمة مرور الآن.**
- **حُذفت قائمة اختيار المادة** بالكامل من واجهة الاختبار. الأسئلة تُسحب عشوائيًا من بنك الأسئلة الموجود (12 سؤالًا تجريبيًا + ما يضيفه المعلم/المعلمة).
- بطاقة التغذية الراجعة تبقى **10 ثوانٍ** أو تُغلق يدويًا، مع عبارات متغيرة للصحيح والخطأ.
- تظل أدوات الإصدار السابق: إدارة الطلاب والفصول والحضور، اختيار عادل، فرق من 2 إلى 12، نقاط الفرق، أسئلة المعلم، التراجع، تصدير CSV، وتبديل اللغة.

## كيف أجربه؟

1. افتح `index.html` بالمتصفح أو انشره عبر GitHub Pages.
2. أدخل اسم المعلمة/المعلم واختر الشخصية واضغط **ابدأ الحصة**.
3. أضف أسماء الطلاب أو جرّب الأسماء التجريبية.
4. اختر الطالب من الزر الأساسي أو **عجلة الأسماء** ثم سجّل الإجابة الصحيحة أو المحاولة.
5. قسّم الصف إلى فرق من صفحة **المجموعات والمسابقات**.
6. أضف أسئلتك في صفحة **الاختبارات**، واختر فريق الإجابة اختياريًا.
7. جرّب **بطاقات التحدي**، وارفع **طاقة الصف** حتى 100% لفتح الصندوق.
8. افتح صفحة **لوحة الشرف** لرؤية النجوم والأوسمة.

**الصوت:** يكون متوقفًا افتراضيًا احترامًا للصوت في الحصة. اضغط **الصوت متوقف** لتفعيله، ثم يمكنك إيقاف أو تشغيل **تشجيع صوتي** مستقلًا. تعتمد جودة ونبرة النطق على الأصوات المتاحة في المتصفح والجهاز؛ إن لم تتوفر أصوات عربية قد تسمع المؤثرات فقط.

## نشر النسخة الجديدة على GitHub Pages

### إذا سبق أن نشرت FairTurn Play:

1. افتح مستودع مشروعك على GitHub ثم ادخل تبويب **Code**.
2. اضغط على ملف **`index.html`** الموجود في المستودع.
3. اضغط زر التعديل **✏️** إن كان متاحًا، أو من تبويب Code استخدم **Add file → Upload files** لرفع ملف `index.html` الجديد **بنفس الاسم وفي نفس المستوى**؛ أكّد استبداله عند الطلب.
4. اختر **Commit changes** في فرع `main`.
5. إذا كان GitHub Pages مفعلًا بالفعل، سيُحدّث نفس الرابط بعد نشر التغيير. قد تحتاج إلى تحديث الصفحة / مسح ذاكرة التخزين المؤقت إن بقيت النسخة القديمة.

### إذا لم تنشره من قبل:

1. افتح [github.com/new](https://github.com/new) وأنشئ مستودعًا عامًا باسم `FairTurn-Play`.
2. من المستودع، **Add file → Upload files** ثم ارفع **`index.html` فقط** إلى جذر المستودع. **لا ترفع ZIP بدلًا من HTML**.
3. اضغط **Commit changes**.
4. افتح **Settings → Pages → Build and deployment** ثم اختر `Deploy from a branch`، الفرع `main`، والمجلد `/(root)` ثم **Save**.
5. الرابط المتوقع بعد تفعيل النشر: `https://YOUR-USERNAME.github.io/FairTurn-Play/`.

## ملاحظات مهمة

- لا تُرفع أسماء الطلاب لخوادم التطبيق، لكن **GitHub Repository عام للكود فقط**؛ لا ترفع قوائم طلاب أو ملفات تحوي بيانات شخصية للمستودع.
- حفظ البيانات محليّ على نفس المتصفح والموقع فقط؛ قد تضيع البيانات عند تنظيف التخزين، الوضع الخفي، أو تبديل الجهاز. استخدام اسماء أولى أو أسماء مستعارة يقلل الإفصاح غير الضروري.
- في حال الانتقال من فتح ملف محلي إلى عنوان GitHub Pages، **لا تنتقل بيانات التخزين تلقائيًا**، وقد تحتاج لإعادة إدخال الأسماء.
- صندوق المكافآت والنقاط عناصر تحفيز صفية وليست تقييمًا تربويًا رسميًا. إحصائية «أجمل تطور» تُحتسب من تغير نسبة الإجابات الصحيحة المسجلة عندما تتوفر أربع فرص أو أكثر.
- المؤثرات والتصميم ثلاثي الأبعاد **مُنفّذة بمؤثرات CSS وWeb Audio محلية** وليست بمحرك ألعاب ثلاثي الأبعاد خارجي.
- يمكن استخدام الموقع مجانًا دون إنترنت بعد تحميل ملف HTML، لكن الحفظ قد لا يعمل في بعض المتصفحات عند فتح ملف محلي؛ GitHub Pages أكثر موثوقية.

**English quick start:** Open `index.html` → enter the teacher name and avatar → add students → use the name wheel, participation tools, team games, random quizzes, challenge cards, class energy, bonus chest and Hall of Fame.
