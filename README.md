# FairTurn Play V4 — النسخة النهائية مع الأصوات الخمسة

الموقع تعليمي تفاعلي، مجاني، بلا حساب أو API مدفوع. النسخة الحالية تحتوي **32 بطاقة تشجيعية أصلية** (20 صحيحة + 12 خطأ/محاولة)، مع **5 أصوات أصلية** أرسلتها صاحبة المشروع. الصور والأصوات مدمجة في ملف `index.html` نفسه، لذلك لا تحتاجين إلى إضافة أي ملفات أو إعداد أصوات يدويًا.

## أسهل طريقة للنشر عبر GitHub

1. افتحي المستودع الموجود الخاص بالمشروع في GitHub. لا تنشئي مستودعًا جديدًا.
2. من **Code → Add file → Upload files**، ارفعي ملف `index.html` من هذه النسخة إلى جذر المستودع واستبدلي النسخة القديمة.
3. اضغطي **Commit changes**. إذا كانت GitHub Pages منشورة مسبقًا، سيتحدث الموقع على الرابط نفسه بعد انتهاء النشر.
4. افتحي الموقع، واضغطي زر **الصوت** إن كان مغلقًا، وجربي «الأصوات» أعلى الصفحة. لا تحتاجين رفع صور أو ملفات MP3 منفصلة.

**ملاحظة:** قد لا تسمح بعض المتصفحات بتشغيل الصوت تلقائيًا قبل أول تفاعل للمستخدم؛ اضغطي زر بدء اللعبة/السؤال أولًا. على الآيباد ينصح بالتجربة من رابط HTTPS الخاص بـGitHub Pages.

## ملفات الصوت الخمسة المدمجة

| الموقف | ملف الصوت المستخرج من مقطع المستخدم | المدة التقريبية |
|---|---|---|
| الإجابة الصحيحة | `sounds/correct-answer.mp3` | 6.1 ثوانٍ |
| الإجابة الخاطئة | `sounds/wrong-answer.mp3` | 7.4 ثوانٍ |
| إعلان المجموعة الفائزة | `sounds/team-applause.mp3` | 6.1 ثوانٍ |
| موسيقى المسابقة | `sounds/team-competition.mp3` | 160 ثانية، تتكرر أثناء التشغيل |
| آخر 10 ثوانٍ من وقت السؤال | `sounds/countdown.mp3` | 10 ثوانٍ، مقتطعة من المقطع الأخير |

المجلد `sounds` في ZIP موجود للاحتفاظ بنسخ منفصلة للتعديل المستقبلي فقط؛ **ليس مطلوبًا رفعه إلى GitHub** لأن الأصوات تعمل من داخل HTML. يمكن ضبط مستوى الصوت من «الأصوات»، وإيقاف الصوت كاملًا من زر الصوت.

## أهم وظائف V4

- اسم المعلمة واسم المادة، وتصميم ملون مناسب للمادة.
- عجلة أسماء ثلاثية الأبعاد بصريًا، مع مراعاة عدالة اختيار الطلاب.
- بطاقات من صورك (20 صحيحة، 12 محاولة/خطأ) تظهر 10 ثوانٍ.
- مساعدة زميل عند الخطأ فقط.
- فرق وتحديات، نقاط + / −، بطاقة خاصة لإعلان المجموعة الفائزة مع التصفيق.
- أسئلة تُدخلها المعلمة فقط، اختيار عشوائي، مؤقت وآخر 10 ثوانٍ بصوت خاص.
- قائمة جميع نجوم المشاركة بالترتيب، أوسمة للمراكز الثلاثة الأولى، ونظام Streak.
- مفاجآت وبطاقات تحدٍ وطاقة الصف والمكافآت.
- يحفظ بيانات الصف محليًا في المتصفح نفسه، ولا يزامن بين الأجهزة.

## تنبيهات مهمة

- يُفضّل التأكد من امتلاك حق النشر العلني للأصوات والصور إذا كان رابط GitHub Pages سيكون عامًا؛ إرسال الملفات لا يثبت ترخيصها لإعادة التوزيع.
- إن كان صوت الجهاز مكتومًا، فلن تُسمع المؤثرات.
- نسخة GitHub المنشورة لا تتغير تلقائيًا بمجرد تحميل هذا الملف؛ يلزم استبدال `index.html` في المستودع.
