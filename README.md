# FairTurn Play V4 — تحديث الخلفيات والأصوات

هذه النسخة تحافظ على الموقع الحالي وبياناته ووظائفه الأساسية، وتتضمن التعديلات الثلاثة الأخيرة المطلوبة:

1. بطاقة اسم المعلمة/المعلم أعلى الصفحة أصبحت أعرض وتعرض الاسم الطويل على أكثر من سطر بدلاً من قصّه.
2. صوت ملف «الإجابة الخاطئة» السابق أصبح يعمل فقط عند الضغط على «لم يجب» في المشاركة. زر «حاول ولم يصب» لا يشغّل الصوت أو التعليق الصوتي الآلي؛ وتستمر بطاقات المحاولة التشجيعية في الظهور.
3. خلفيات المواد الثلاث التي أُرسلت أصبحت خلفيات للصفحة كاملة، بحجم متناسب مع الشاشة ووضوح بصري 50% عبر طبقة فاتحة:
   - التربية الإسلامية: الزخارف الهندسية.
   - العلوم: رسومات العلوم.
   - اللغة العربية: الحروف العربية.

الصور الثلاث **مدمجة داخل `index.html`**، بالإضافة إلى صور بطاقات التشجيع الـ32 والأصوات الخمسة الموجودة سابقاً. لا توجد ملفات إضافية مطلوبة لتشغيل الموقع، ولا يوجد اتصال بخدمة مدفوعة.

## تحديث GitHub Pages

1. افتحي المستودع الموجود `FairTurn-Play`.
2. ارفعي ملف `index.html` من هذه الحزمة إلى المجلد الرئيسي للمستودع بدلاً من الملف القديم.
3. اضغطي **Commit changes** ثم افتحي رابط موقعك المعتاد.
4. إذا ظهر الشكل القديم، حدّثي الصفحة تحديثًا كاملاً (Ctrl + Shift + R على الكمبيوتر).

لم تُزوَّد صور جديدة لبقية المواد، لذلك تحتفظ بالتصميم العام الحالي حتى يتم إرسال خلفياتها.

**تنبيه حقوق النشر:** بعض الصور المرسلة تحمل علامات مصدر/شعارات. قبل نشر الموقع للعامة، تأكدي أن لديك حق إعادة استخدام الصور والأصوات.
