# FairTurn Play V4 — تحديث أصوات الآيباد والاختبارات والمجموعات

## التعديلات في هذه النسخة

- عند اختيار **إجابة خاطئة في الاختبارات**، يعمل ملف صوت المحاولة/الإجابة الخاطئة الذي أرسلته المعلمة.
- عند اختيار **إجابة صحيحة**، يعمل ملف نجاح المعلمة الأصلي فقط، دون نغمات مولّدة أو تعليق صوتي آلي مصاحب.
- عند بقاء آخر **10 ثوانٍ من وقت السؤال**، يبدأ ملف العد التنازلي الأصلي. أُضيف دعم Web Audio لاستمرار الصوت بعد نقرة بدء السؤال على أجهزة iPad والمتصفحات التي تمنع التشغيل التلقائي المؤجّل.
- في صفحة المجموعات، أضيف زران كبيران **+ و−** لتحديد عدد الفرق بين **2 و12**.
- في صفحة المشاركة، يبقى «حاول ولم يصب» **صامتًا**، بينما «لم يجب» يستخدم ملف صوت الخطأ، وفق التخصيص السابق.
- لم تتغير بيانات الصفوف والأسئلة المحفوظة، ولا بطاقات التشجيع، ولا خلفيات المواد الحالية.

## نشر التحديث على GitHub Pages

1. فكّي ضغط الحزمة.
2. افتحي مستودع GitHub `hlm2001-ai/FairTurn-Play`.
3. ارفعي **الأربعة ملفات التالية في المجلد الرئيسي للمستودع** وليس داخل مجلد فرعي:
   - `index.html`
   - `v4-bg-islamic-4k.png`
   - `v4-bg-science-4k.png`
   - `v4-bg-arabic-4k.png`
4. عند وجود ملفات تحمل الأسماء نفسها في المستودع، استبدليها بالإصدارات الجديدة، ثم اضغطي **Commit changes**.
5. افتحي `https://hlm2001-ai.github.io/FairTurn-Play/` وجدّدي الصفحة. على الآيباد، استخدمي Reload أو نافذة خاصة إذا بقيت النسخة المخبأة.

الأصوات الخمسة وبطاقات الصور الـ32 مدمجة داخل `index.html`. صور خلفيات المواد الثلاث **ملفات مستقلة** وتحتاج إلى الرفع مع HTML. لا ترفعي ملف ZIP نفسه إلى Pages.

ملاحظة: تم اختبار التفاعل آليًا على متصفح Chromium بحجم شاشة الآيباد، وليس على جهاز iPad Safari فعلي. قد يتطلب تشغيل الأصوات في Safari لمس الشاشة أولًا، وهو سلوك مفروض من المتصفح. تأكدي من حقوق استخدام المواد الصوتية والبصرية قبل نشرها للعامة.
